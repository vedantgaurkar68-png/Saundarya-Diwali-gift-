# A Little Diwali Surprise ❤️

A responsive, romantic Diwali greeting website made with plain HTML, CSS and JavaScript.

## Run it in VS Code
1. Extract `diwali-for-my-love.zip`.
2. Open the `diwali-for-my-love` folder in VS Code.
3. Open `index.html` in a browser. Recommended: install the **Live Server** extension, right-click `index.html`, then choose **Open with Live Server**.
4. Keep the `assets` folder beside `index.html`; the photos are loaded from there.

## Personalize before sharing
- Open `index.html` and edit the note text, captions and headings.
- Replace photos inside `assets` while keeping the same filenames (`photo-1.jpg` through `photo-4.jpg`), or update the image paths in `index.html`.
- The music button plays a small synthesized chime pattern using the browser. It does not stream or include a copyrighted song.
- Test on your phone before sharing. GitHub Pages can host this static site for free.

## Privacy
The four photos are stored locally in this project folder. They are not uploaded anywhere by this website itself. If you publish the site publicly, anyone with the link may be able to view the photos.
